Table Badness

可读性感知的表格布局。表格被看成由列边界和行边界组成的网格：跨列、跨行的格子与普通格子用同一套模型，表格高度是行边界上的最长路径。每张表都是真实 HTML 表格，由浏览器按相同字体、内边距和断行规则排版；粉色虚线框是可用宽度。指标从实际渲染测量，不取自算法的预测。拖动列边线可手动调整（← → 键也可），双击边线或点“恢复”回到算法结果。

列宽随可用宽度的变化

Table Badness v2 只计算一次列宽路径（有时一步同时加宽几列，以降低由多个并列最高格子撑起的行）；可用宽度变化时只查表，每列宽度单调不减。最小高度优化每个宽度单独求解，列宽会来回跳动。竖线是当前宽度。
